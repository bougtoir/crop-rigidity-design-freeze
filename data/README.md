# data/

`data/raw/` holds the downloaded originals (~1.4 GB): FAOSTAT QCL feather,
MapSPAM 2005/2010 geotiff zips, GAEZ v4 tifs, MIRCA zips, ISIMIP3b netCDFs,
SPEIbase netCDFs. They are committed to the repository (not embedded in the
zip deliverable) and are fully re-acquirable via `scripts/01_acquire_data.py`;
URL/version/license/SHA-256 for every file is in
`CROP_RIGIDITY_DESIGN_FREEZE/DATA_SOURCE_LEDGER_v2.csv`.
