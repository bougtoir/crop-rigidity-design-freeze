# 11 Next-phase recommendation

Options, in order of expected information gain:

1. **Stop and publish the null** (e.g. a null-results or
   specialty venue): two-scale, pre-registered, powered,
   outcome-blind nulls have genuine value for the adaptation
   literature; the SPAM2010 divergence becomes a discussion point on
   exposure vintage.
2. **Redirect the mechanism to a domain with observable
   transformation events** (the feasibility audit's core finding:
   pixel-level change is not observable; event-level data are the
   binding constraint) — new feasibility cycle required.
3. **Do NOT** re-spec the current model for a favorable result, and
   do NOT escalate the SPAM2010 sensitivity to primary: that would be
   post-hoc selection.

Recommendation: option 1 or 2; the current programme has cleanly
answered the question it was designed to ask.
